# M6 plan — Exports (SPEC §12, §16 M6)

Written 2026-09-18 while Jeremy was away; implemented in the same commit.

| Export | How |
|---|---|
| Markdown / plain text | `ExportRenderer` (pure, tested): title, date · duration, speakers, summary sections per template, `- [ ]` action items with owner / due / `@ mm:ss`, transcript with timestamps behind the "Include transcript" toggle |
| PDF | `PDFComposer` in `LiveExportService`: US Letter, Core Text pagination of the same sections, "Title · Page n" footer; tested in the Simulator for a real multi-page `%PDF-` |
| Copy | `ExportController.copySummary` / `copyActionItems` → `UIPasteboard` |
| Email | `MFMailComposeViewController` prefilled; client template asks the summarizer for the follow-up email (SPEC §11.4); without a Mail account the text goes to the share sheet |
| Reminders | `RemindersSheet`: list picker (default list first), select items, already-sent items disabled; `LiveExportService.createReminders` via EventKit full access (`NSRemindersFullAccessUsageDescription`), title = task, notes = owner + "From: <title> @ mm:ss" + spoken due phrase, due date + alarm when resolved; reminder IDs stored in `SummaryRecord.actionItemsState` |
| Audio | `AVAssetExportSession` passthrough to `.m4a` |

Share menu lives in the detail toolbar (`detail.share`). Files are written to `tmp/Exports/<YYYY-MM-DD Title>.<ext>` and handed to `UIActivityViewController`.

Device checks: open each file from the share sheet in Files / Notes / Obsidian; Mail draft appears prefilled; Reminders shows the items with due dates in the chosen list; the `.m4a` plays in Files.
